# W-StoreMgData

# سیستم فروشگاهی White Label - معماری مستقل کسب و کار

## معرفی پروژه

این پروژه یک هسته نرم افزاری فروشگاهی مستقل است که می‌تواند برای انواع کسب و کارها استفاده شود.

نمونه خروجی‌های قابل تولید:

- فروشگاه موبایل
- بوتیک
- فروشگاه لوازم آرایشی
- فروشگاه عمومی
- سایر کسب و کارهای فروشگاهی

منطق اصلی برنامه مستقل از نوع کسب و کار طراحی می‌شود.

---

# معماری اصلی پروژه

ساختار کلی:

```
Core Engine
      +
Business Profile
      +
Feature Modules
      =
Application مستقل
```

---

# Business Profile System

تمام اطلاعاتی که مربوط به ظاهر و هویت کسب و کار است از کد اصلی جدا نگهداری می‌شود.

شامل:

- نام برنامه
- نام فروشگاه
- شناسه کسب و کار
- Package Name
- لوگو
- آیکون
- تصاویر
- رنگ‌بندی
- متن‌ها
- ماژول‌های فعال

با تغییر Profile می‌توان نسخه جدیدی از برنامه ساخت بدون تغییر در هسته اصلی.

---

# ساختار توسعه ماژول‌ها

هر امکان جدید به صورت سلسله مراتبی اضافه می‌شود.

مثال:

```
Store System
│
├── Dashboard
│
├── Product Management
│   ├── Add Product
│   ├── Edit Product
│   └── Delete Product
│
├── Inventory
│   ├── Stock Entry
│   ├── Stock Exit
│   └── Low Stock Alert
│
├── Sales
│   ├── Invoice
│   ├── Payment
│   └── Sales History
│
├── Customer
│
└── Reports
```

هر قابلیت جدید باید در جایگاه مربوط به خود اضافه شود.

---

# قوانین کدنویسی

- تمام فایل‌های Kotlin دارای توضیحات فارسی هستند.
- وظیفه هر فایل در ابتدای آن نوشته می‌شود.
- ارتباط فایل با سایر بخش‌ها مشخص می‌شود.
- اطلاعات کسب و کار داخل Feature ها نوشته نمی‌شود.
- تمام اطلاعات قابل تغییر از Business Profile خوانده می‌شوند.
