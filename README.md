# W-StoreMgData

# سیستم فروشگاهی White Label - هسته مستقل کسب و کار

## معرفی پروژه

این پروژه یک هسته نرم افزاری فروشگاهی مستقل است که می‌تواند برای ساخت چندین برنامه مستقل استفاده شود.

نمونه خروجی‌ها:

- مدیریت فروشگاه موبایل
- مدیریت بوتیک
- مدیریت فروشگاه لوازم آرایشی
- مدیریت سایر کسب و کارهای فروشگاهی

اصل معماری:

```
Core Engine
      +
Business Profile
      +
Feature Modules
      =
Application مستقل
```

---

# معماری Business Profile

اطلاعات وابسته به هر کسب و کار از کد اصلی جدا است.

شامل:

- شناسه کسب و کار
- نام برنامه
- نام فروشگاه
- Package Name
- آیکون برنامه
- لوگو
- تصاویر
- رنگ‌ها
- متن‌ها
- تنظیمات ظاهری
- امکانات فعال

برای ساخت برنامه جدید فقط Profile تغییر می‌کند و Core ثابت باقی می‌ماند.

```
        v

        v

        |
        v

```

# استاندارد سورس کد

تمام فایل‌ها باید شامل توضیحات فارسی باشند:

- نام فایل
- ماژول مربوطه
- وظیفه فایل
- ارتباط با سایر فایل‌ها
- نکات توسعه آینده

نمونه:

```
نام فایل:
ProductRepository.kt

ماژول:
مدیریت کالا

وظیفه:
ارتباط بین منطق برنامه و منبع داده
```
