# قوانین اصلاح نام گذاری معماری

## هدف

هسته نرم افزار نباید به هیچ کسب و کاری وابسته باشد.

نام هایی مانند:

- mobile
- beauty
- boutique
- cosmetics

نباید داخل Core استفاده شوند.

این موارد فقط Business Profile هستند.

## قوانین

قابلیت نرم افزاری = Module

مثال:

- Warranty
- Repair
- Appointment
- Serial Tracking

اطلاعات متغیر = Attribute Schema

مثال:

- Color
- Size
- Volume
- Storage

Core فقط مفاهیم عمومی را می شناسد.
نوع کسب و کار فقط از Business Profile خوانده می شود.
