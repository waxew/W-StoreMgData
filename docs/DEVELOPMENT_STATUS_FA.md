# وضعیت توسعه W-StoreMgData

## مرحله فعلی

نسخه پایه موتور فروشگاهی White Label در حال توسعه است.

## تصمیمات معماری ثبت شده

### 1. Core مستقل

منطق اصلی برنامه نباید وابسته به نوع کسب و کار باشد.

### 2. Business Profile

تمام اطلاعات قابل تغییر کسب و کار در Profile نگهداری می‌شود:

- نام برنامه
- نام فروشگاه
- شناسه کسب و کار
- آیکون
- لوگو
- تصاویر
- رنگ‌ها
- متن‌ها
- ماژول‌های فعال

### 3. توسعه ماژولار

هر قابلیت جدید طبق ساختار زیر اضافه می‌شود:

```
Feature
│
├── Entity
├── Data
├── Repository
├── UseCase
├── ViewModel
├── UI
└── Documentation
```
