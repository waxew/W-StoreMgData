# معماری Product Engine

## هدف

Product Engine باید مستقل از نوع کسب و کار باشد.

در Core نباید مفاهیمی مانند:

- Mobile
- Beauty
- Boutique

وجود داشته باشد.

## ساختار

Product Core:

- نام محصول
- دسته بندی
- برند
- قیمت
- تصویر

Attribute Schema:

برای اطلاعات متغیر:

- رنگ
- سایز
- ظرفیت
- حجم
- تاریخ انقضا

Module:

برای قابلیت های دارای منطق:

- گارانتی
- تعمیرات
- رهگیری شناسه

Business Profile مشخص می‌کند کدام قابلیت‌ها فعال باشند.
