# وضعیت تکمیل ماژول مشتری

## هدف

ماژول مشتری یکی از بخش‌های Core سیستم مدیریت کسب‌وکار است و مستقل از نوع فروشگاه طراحی شده است.

## ساختار

```
Customer
├── Entity
├── DAO
├── Repository
├── UseCase
├── ViewModel
└── UI
```

## قوانین

- اطلاعات عمومی مشتری در Core نگهداری می‌شود.
- اطلاعات اختصاصی هر کسب‌وکار با Dynamic Attribute اضافه می‌شود.
- هیچ وابستگی به موبایل فروشی، بوتیک یا سالن زیبایی وجود ندارد.

## توسعه آینده

- جستجو مشتری
- تاریخچه خرید
- ارتباط با فاکتور
- سطح‌بندی مشتری
- گزارش مشتریان
