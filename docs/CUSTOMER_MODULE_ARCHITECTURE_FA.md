# معماری ماژول مشتری

## هدف

ماژول مشتری یکی از بخش های اصلی هسته مدیریت کسب و کار است و به نوع فروشگاه وابسته نیست.

## ساختار

Customer Module

```
Customer
├── Entity
├── DAO
├── Repository
├── UseCase
├── ViewModel
└── UI
```

## قوانین توسعه

- اطلاعات عمومی مشتری در Core نگهداری می‌شود.
- اطلاعات اختصاصی هر کسب و کار با Custom Attribute اضافه می‌شود.
- هیچ فیلدی مانند IMEI، سایز لباس یا مشخصات خدمات نباید داخل Customer عمومی قرار گیرد.

## نمونه استفاده

فروشگاه موبایل:
- تاریخچه خرید
- گارانتی
- ارتباط با کالا

بوتیک:
- سایز مورد علاقه
- رنگ مورد علاقه

سالن زیبایی:
- تاریخچه مراجعه
- خدمات دریافت شده

## وضعیت فعلی

- Entity: تکمیل
- DAO: ایجاد شده
- Repository: ایجاد شده
- UseCase: در حال تکمیل
- UI: مرحله بعد
