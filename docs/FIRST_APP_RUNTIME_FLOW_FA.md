# جریان اجرای اولیه برنامه

## مسیر اجرای برنامه

1. MainActivity اجرا می‌شود.

2. AppTheme ظاهر برنامه را آماده می‌کند.

3. AppNavigation مدیریت صفحات را انجام می‌دهد.

4. Screen ها از ViewModel استفاده می‌کنند.

5. ViewModel منطق را از UseCase دریافت می‌کند.

## قوانین معماری

- MainActivity نباید منطق کسب‌وکار داشته باشد.
- نوع فروشگاه داخل UI هاردکد نمی‌شود.
- اطلاعات برند و تنظیمات از Business Profile تامین خواهد شد.

## هدف نهایی

یک سورس مشترک که بتواند با تغییر Business Profile برای کسب‌وکارهای مختلف خروجی مستقل ایجاد کند.
