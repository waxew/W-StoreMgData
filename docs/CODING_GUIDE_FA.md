# راهنمای کدنویسی پروژه W-StoreMgData

## قوانین مستندسازی

تمام فایل‌ها باید در ابتدای خود توضیح فارسی داشته باشند.

الگوی توضیح:

```
نام فایل:

بخش:

وظیفه:

ارتباط با:

توضیحات توسعه:
```

## قوانین معماری

1. هیچ اطلاعات برند یا فروشگاه داخل منطق برنامه نوشته نمی‌شود.

2. تمام اطلاعات قابل تغییر از Business Profile دریافت می‌شود.

3. هر قابلیت جدید به صورت ماژول مستقل اضافه می‌شود.

## ترتیب اضافه کردن قابلیت‌ها

مثال:

Product Module

- Entity
- Database
- Repository
- UseCase
- ViewModel
- UI
- Documentation

هر بخش قبل از رفتن به قابلیت بعدی تکمیل و ثبت می‌شود.

## هدف

حفظ قابلیت تبدیل یک سورس به چندین محصول مستقل.
