# معماری هسته اصلی W-StoreMgData

## هدف
این بخش هسته ثابت برنامه فروشگاهی است و نباید اطلاعات یک کسب و کار خاص داخل آن قرار بگیرد.

## قوانین
- Core فقط منطق عمومی را نگهداری می‌کند.
- نام فروشگاه، لوگو، رنگ، متن و تصاویر از Business Profile دریافت می‌شوند.
- هر ماژول باید مستقل و قابل توسعه باشد.

## ساختار توسعه

```
Core
 |
 +-- Business Profile
 |
 +-- Data Layer
 |
 +-- Domain Layer
 |
 +-- Feature Modules
```

## استاندارد فایل‌ها
هر فایل باید شامل:
- نام فایل
- ماژول مربوطه
- وظیفه
- ارتباط با سایر بخش‌ها
- توضیحات توسعه آینده
باشد.
