# ترتیب توسعه قابلیت ها

این سند ترتیب استاندارد اضافه شدن امکانات به سیستم را مشخص می کند.

## مرحله ۱ - Core Engine

- Database Base
- Configuration
- Business Profile
- Theme Engine
- Permission System

## مرحله ۲ - Customer Module

- Entity مشتری
- ذخیره اطلاعات مشتری
- جستجو
- تاریخچه خرید
- اتصال به فروش و فاکتور

## مرحله ۳ - Product Module

- تعریف کالا
- دسته بندی
- ویژگی های پویا
- تصویر کالا

## مرحله ۴ - Inventory Module

- ورود کالا
- خروج کالا
- موجودی
- گزارش انبار

## مرحله ۵ - Sales Module

- ثبت فروش
- فاکتور
- پرداخت
- تاریخچه فروش

## مرحله ۶ - Business Specific Modules

نمونه:

Mobile Store:
- IMEI
- Warranty

Boutique:
- Size
- Color

Beauty:
- Service
- Reservation

---

تمام امکانات باید به صورت ماژول مستقل توسعه داده شوند تا در Business Profile قابل فعال یا غیرفعال شدن باشند.
