# وضعیت ماژول مشتری

## هدف

ماژول مشتری یکی از بخش‌های اصلی هسته مدیریت کسب‌وکار است و مستقل از نوع فروشگاه طراحی می‌شود.

## ساختار فعلی

```
Customer Module
│
├── Entity
├── DAO
├── Repository
├── UseCase
└── ViewModel
```

## قوانین

- اطلاعات عمومی مشتری در Core قرار می‌گیرد.
- اطلاعات اختصاصی کسب‌وکارها با Custom Attribute اضافه می‌شود.
- هیچ وابستگی به موبایل فروشی، بوتیک یا سالن وجود ندارد.

## ادامه توسعه

مراحل بعدی:

1. اتصال UseCase به Repository
2. ساخت ViewModel
3. ساخت رابط کاربری مشتری
4. اضافه کردن جستجو و تاریخچه مشتری
