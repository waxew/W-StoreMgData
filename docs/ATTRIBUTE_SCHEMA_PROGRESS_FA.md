# وضعیت توسعه Attribute Schema

## هدف

مدیریت فیلدهای متغیر کسب و کار بدون تغییر Core.

## جریان

Business Profile

↓

Attribute Schema

↓

Attribute Definition

↓

Attribute Value

↓

Dynamic UI

## مثال

فروشگاه موبایل:

- IMEI
- Storage
- Warranty

بوتیک:

- Size
- Color
- Material

این موارد در Core به صورت کلاس ثابت تعریف نمی شوند.
