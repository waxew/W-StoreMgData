# ساختار ماژول های اصلی سیستم جامع فروشگاهی

## هدف

این فایل معماری ماژول های عمومی سیستم را مشخص می کند.

هسته برنامه نباید وابسته به یک نوع کسب و کار باشد. هر کسب و کار فقط با فعال کردن ماژول ها و تنظیمات خود ساخته می شود.

---

# Core Modules

## Customer Management

ماژول عمومی مدیریت مشتری.

شامل:

- تعریف مشتری
- ویرایش اطلاعات مشتری
- ذخیره شماره تماس
- آدرس
- یادداشت ها
- سابقه تعاملات
- تاریخچه خرید

این ماژول برای همه کسب و کارها قابل استفاده است.

---

## Product Management

مدیریت کالا به صورت عمومی.

اطلاعات پایه:

- نام کالا
- دسته بندی
- برند
- قیمت خرید
- قیمت فروش
- تصویر
- موجودی

ویژگی های خاص مانند IMEI موبایل یا سایز لباس نباید داخل Core قرار بگیرند و باید به صورت Attribute یا Module اضافه شوند.

---

## Dynamic Attributes

برای ویژگی های اختصاصی هر کسب و کار.

مثال:

موبایل فروشی:

- IMEI
- مدل
- حافظه
- رنگ

بوتیک:

- سایز
- رنگ
- جنس

لوازم آرایشی:

- حجم
- تاریخ انقضا

---

## Business Profile

هر نسخه از برنامه توسط یک Profile مشخص می شود.

Profile تعیین می کند:

- نام برنامه
- برند
- آیکون
- تصاویر
- رنگ ها
- ماژول های فعال
- ویژگی های اختصاصی

---

# قانون توسعه

هیچ اطلاعاتی که فقط مربوط به یک کسب و کار است نباید داخل Core نوشته شود.

Core ثابت است.

Business Profile قابل تغییر است.
