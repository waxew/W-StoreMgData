# معماری پروژه W-StoreMgData

## هدف پروژه

این پروژه یک هسته نرم افزار مدیریت فروشگاهی قابل شخصی سازی است.

اصل معماری:

Core ثابت + Configuration قابل تغییر

## قانون شخصی سازی

تمام اطلاعات وابسته به کسب و کار در فایل تنظیمات جدا نگهداری می شود.

موارد قابل تغییر:
- نام برنامه
- نام فروشگاه
- نوع کسب و کار
- رنگ ها
- لوگو
- تصاویر
- فعال بودن ماژول ها

## ماژول های اصلی

- Dashboard
- Product
- Inventory
- Sales
- Customer
- Supplier
- Reports
- Settings

## قوانین کدنویسی

تمام فایل های Kotlin دارای توضیح فارسی خواهند بود.
هر فایل مشخص می کند:
- وظیفه فایل
- ارتباط با سایر بخش ها
- موارد قابل توسعه
