## هدف

این بخش توضیح می‌دهد اطلاعات مشتری چگونه در معماری برنامه حرکت می‌کند.

## قوانین

- مشتری یک قابلیت عمومی سیستم است.
- نباید وابسته به نوع کسب‌وکار باشد.
- اطلاعات اختصاصی کسب‌وکار از طریق Module و Attribute مدیریت می‌شود.

نمونه:

شماره تماس، نام و ایمیل در Core مشتری قرار می‌گیرد.

اطلاعات اختصاصی مانند تاریخچه تعمیر یا رزرو از طریق Module اضافه می‌شود.
