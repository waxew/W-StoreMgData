# تصمیمات معماری هسته جامع مدیریت کسب و کار

## هدف
این پروژه یک نرم افزار مخصوص یک کسب و کار خاص نیست. هدف ساخت یک موتور نرم افزاری عمومی است که بتوان از آن نسخه های مختلف برای کسب و کارهای متفاوت تولید کرد.

## قانون اصلی
هسته برنامه نباید اطلاعاتی مانند نام فروشگاه، نوع کالا یا ویژگی اختصاصی یک صنف را داخل خود ذخیره کند.

ساختار:

```
Core Engine
+
Business Profile
+
Feature Modules
+
Custom Attributes
=
Application مستقل
```

## Customer Module

ماژول مشتری جزو هسته اصلی است.

شامل:

- اطلاعات پایه مشتری
- اطلاعات تماس
- آدرس
- یادداشت
- تاریخچه خرید
- ارتباط با فروش و فاکتور

## Product Module

محصول به صورت عمومی طراحی می شود.

اطلاعات ثابت:

- نام
- دسته بندی
- قیمت
- تصویر
- موجودی

ویژگی های اختصاصی از طریق Custom Attributes اضافه می شوند.

## Custom Attributes

ویژگی هایی مانند:

- IMEI برای موبایل
- سایز برای پوشاک
- حجم برای لوازم آرایشی

نباید داخل Product Core قرار بگیرند.

## استاندارد توسعه

1. مستندات فارسی
2. Domain Model
3. Data Layer
4. Repository
5. UseCase

7. UI
