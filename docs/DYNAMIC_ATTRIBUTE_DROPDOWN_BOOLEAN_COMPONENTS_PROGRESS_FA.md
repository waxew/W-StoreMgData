# Dynamic Attribute Dropdown & Boolean Components

## هدف

تکمیل Component های باقی مانده Dynamic Attribute UI.

## Dropdown

برای Attribute های ENUM استفاده می شود:

- Size
- Color
- Category
- Brand

## Boolean

برای Attribute های منطقی استفاده می شود:

- Active
- Available
- Warranty Enabled

## قانون معماری

این Component ها فقط Attribute Type را می شناسند و هیچ وابستگی به Business Profile ندارند.
