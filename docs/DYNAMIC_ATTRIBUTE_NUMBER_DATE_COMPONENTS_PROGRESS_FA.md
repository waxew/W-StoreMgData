# پیشرفت Dynamic Attribute Components

## Number Field

برای Attribute های عددی استفاده می‌شود:

- Price
- Quantity
- Weight
- Volume

## Date Field

برای Attribute های تاریخ:

- Warranty Date
- Expiration Date
- Manufacture Date

این Component ها فقط نوع داده را می‌شناسند و وابستگی به Business Profile ندارند.
