# گزارش پیشرفت ماژول مشتری

## هدف

ماژول مشتری یکی از اجزای Core سیستم مدیریت کسب و کار است و به نوع کسب و کار وابسته نیست.

## ساختار

```
Customer
├── Entity
├── DAO
├── Repository
├── UseCase
├── ViewModel
└── UI
```

## وضعیت

- Entity: تکمیل شده
- DAO: تکمیل شده
- Repository: تکمیل شده
- UseCase: تکمیل شده
- ViewModel: تکمیل شده
- UI Foundation: در حال توسعه

## قوانین

اطلاعات اختصاصی کسب و کار مانند IMEI یا ویژگی های تخصصی نباید داخل مشتری عمومی قرار گیرد و باید از Custom Attribute Engine استفاده شود.
