# معماری Runtime برنامه

## هدف

این سند توضیح می‌دهد برنامه هنگام اجرا چگونه از تنظیمات کسب‌وکار استفاده می‌کند.

## جریان اجرا

```
Android Application
        |
        v
Application Runtime
        |
        v
Business Profile Loader
        |
        v
Module Loader
        |
        v
Core Features
        |
        v
UI
```

## قانون معماری

Core نباید بداند برنامه برای چه کسب‌وکاری ساخته شده است.

اطلاعاتی مانند:

- نام فروشگاه
- لوگو
- ماژول‌های فعال
- فیلدهای اختصاصی

از Business Profile دریافت می‌شوند.

## مثال

یک Core مشترک می‌تواند با تغییر Profile به نسخه‌های مختلف تبدیل شود:

- فروشگاه موبایل
- بوتیک
- لوازم آرایشی

بدون تغییر در Core.
